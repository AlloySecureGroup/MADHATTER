Method

The lab supports both a continuous embedding adversary and a discrete vocabulary adversary. LoRA remains the trainable model variable.

inner: perturbation ← arg max local loss    |    sensitive outer: min θ [CEclean − λ JS(clean, perturbed)]    |    robust outer: min θ [CEadv + λ KL(clean || adv)]

Two inner loops

Embedding PGD projects δ into a norm budget. Discrete mode uses a HotFlip-style first-order score and verifies real token substitutions against the loaded model.

Prompt-only perturbation

Only user-prompt positions are editable. Chat-control tokens and supervised response tokens remain untouched.

LoRA outer loop

Robust mode minimizes adversarial loss. Sensitivity mode minimizes clean CE while maximizing bounded clean-vs-perturbed JS divergence, so output token probabilities separate without globally ascending the model loss.

For a research-grade evaluation, hold out prompts, sweep ε, compare clean quality versus robust quality, and run several random PGD restarts. A single restart can underestimate the true local maximum.
